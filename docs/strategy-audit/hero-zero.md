## Hero-Zero (Expiry-Day OI) — automation audit

**Scope.** Audits the automation of Siva strategy #7 "Hero-Zero (Expiry-Day OI Strategy)" (doc §3.7 narrative, §6.7 machine-readable block; sizing/SL cross-refs §2.12-58, §5.7) against the three seeded YAMLs (`scalp-hero-zero-nifty.yaml`, `scalp-hero-zero-sensex-niftyoi.yaml`, `scalp-hero-zero-sensex-sensexoi.yaml`), the `hero-zero`-tagged engine path (`HeroZeroGate`, `HeroZeroStrikeSelector`, `ScalperConfluenceGate`, `ScalperConfig`, `ScalperGates`, `ScalperOiProps`), and the OI/VIX/IV feeds (`MarketOiClient` / `ConnectingDotsService`). Hero-Zero has a real dedicated pre-gate (`HeroZeroGate`) and a literal strike selector, so the structural core of the strategy is genuinely automated — the gaps are concentrated in the discretionary "data fidelity" reads (the >50% confirmation on the *specific* strike, VWAP-pinning skip, IV-flat-both-sides skip, PE-at-call-discount caution) and in the risk-sizing numbers (10%-of-profits, index-scaled point SL), which are not encoded and not on the manual checklist. Derived-history caveat applies: on a backtest the OI/Dow/IV factors degrade to NEUTRAL, so `HeroZeroGate` will rarely or never fire on historical replay — but it is judged here on code presence, not backtest behaviour.

### Not automated (gaps)

- **Index-scaled point SL (BN ~75 / Nifty ~30 / wider Sensex-Bankex)** — the S22-resolved structural number is entirely absent; only the 50%-premium SL + opposite-extreme stop exist.
- **10%-of-profits / never-capital sizing** — replaced by a flat `budget_inr: 2000`; the "stake only a slice of profits" discipline is unenforced (gate comment admits it).
- **Conditional 3:10 PM no-move exit** — the S22 tighter time exit is not encoded (only the 15:20 square-off).
- **VWAP-pinning sit-out** and **round-strike double-zero pin warning** — no skip when sellers pin price at VWAP / a round strike into the close.
- **IV-flat-both-sides = no trade** — `ceIvAvg6`/`peIvAvg6` are in the context but `HeroZeroGate` never reads them (the data is already available — a wirable gap).
- **Do-NOT-buy-PE-when-CE-at-a-discount caution** and **premium-adjustment fake-out** awareness — not gated.
- **"Drastic" OI-fall magnitude floor** — short-covering passes on any negative side delta; `ScalperOiProps.drasticFloor` exists but is not consulted by the gate.
- **Per-strike >50% OI+price confirmation** — the >50% confirmation runs on the index-level spurt + call/put imbalance, not on the actual entry strike (S24 (d) per-strike thresholds).
- **Anti-averaging-a-loser** — only incidentally covered by the 1-position cap.
- **Evening prep ritual** (4-5 strikes either side, round strikes, 3-4 days OI) — human pre-market task, not automated.
- **Timing drift** — the encoded 14:30 entry floor is looser than the S21/S23 "~2:30-2:45 PM" tightening.
- **Expiry-day OI double-confirmation pattern** (short-build Call + long-build Put ⇒ buy Put; sellers shifting Call→Put writing ⇒ buy Call) — not gated; the gate uses same-side short-covering instead (**v2-added**).
