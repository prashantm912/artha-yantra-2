## Two Candle Theory (Siva #1) — automation audit

Scope: audits the **Two Candle Theory** strategy (doc §3.1, evolution §5.1, machine-readable appendix §6.1)
against its automation — the three `scalp-two-candle-*.yaml` files plus the typed gate/seam code
(`TwoCandleGate`, `ScalperConfluenceGate`, `ScalperGates`, `ConnectTheDotsScorer`, `ScalperConfig`,
`StrikePicker`, `ScalperManualChecks`). The namesake 2-candle pattern + 1st-candle stop are genuinely
encoded; most of the surrounding confluence (OI/VIX/breadth/IV) is scored as soft "dots" rather than as the
hard preconditions the doc states, and a large share of the doc's discretionary management (averaging ladder,
trailing, target %, RSI cool-off, 2nd-candle structure nuances, Sensex point-scaling) is either un-automated
or carried only by the generic 7-item `ScalperManualChecks` checklist. Derived-history caveat applies to the
OI/VIX/IV/breadth dots (they degrade to NEUTRAL on backtests per CLAUDE.md); status below judges **code
presence**, not backtest behaviour.

### Not automated (gaps)

- **RSI overbought cool-off (§3.1 S21f/S24a):** no "wait for RSI >80/85 to cool, enter on the pullback candle" logic — fully manual.
- **Alternate stops (§3.1 exit / S21b / S24c):** VWAP-as-SL-when-extended and the large-1st-candle (1st-high / 2nd-low) alternate are not encoded — the stop is always the 1st-candle extreme.
- **Target & trailing (§3.1 exit / 6.1 scaling):** no 1–2% / next-S-R target, no PSAR-then-Supertrend trailing; exit is only a VWAP-cross signal or a 10-bar timeout.
- **Averaging ladder (§3.1 risk / S22d):** the 3%→+7%→≤20% scale-in and the WMA→ST→VWAP 25%/more/max ladder are entirely manual (`max_positions:1`, fixed budget).
- **"HIGH" one-sided OI difference (§3.1 #6) & >50% Trending-OI sizing (S21g):** OI confirmation is a soft weighted dot here, never the hard "marginal = no trade" block; the `oi-cross-filter` 50% gate is not armed on two-candle YAMLs.
- **"ALL soldiers on the far side" conjunction (§3.1 #8):** `indicatorAlignment` is implemented but not wired as a hard gate — PSAR/VWMA/ST are only soft dots, so a signal can fire with some against price.
- **One-rejection-trade cap (§3.1 S21c), 2-candle+Golden-Crossover combo (S21d), VWAP-break-with-volume vs fake-breakout (§3.1 exit):** none modelled.
- **Sensex ~3× point-scaling of SL/target (§4.16):** the instrument decoupling is automated; the point-scaling of risk numbers is not.
- **Bearish (PUT) two-candle:** code supports the PE side but no PE YAML is registered — bearish two-candle is manual.
- **RSI band mismatch (§3.1 vs §4.2):** the live gate uses §4.2's CE 60–80 / PE 20–40, not §3.1's 50–75 — verify this is the intended band.
